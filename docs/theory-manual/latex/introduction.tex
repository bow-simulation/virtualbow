\chapter{Introduction}

VirtualBow is a software tool for designing and simulating bows.
This documentation explains the theory and reasoning behind the internal simulation methods used for computing the results.
It is still a work in progress and continues to evolve alongside the software, so it may not always be complete and up to date.
Note that reading and understanding this documentation is not required for using the VirtualBow software successfully -- the user manual should be sufficient for that.
Instead, it serves as a reference for developers and interested users who want to learn more about the internals of VirtualBow.

The chapters of this document roughly follow the course of a bow simulation, from the underlying model to the numerical methods used to solve it.
The \textit{\nameref{chap:bow-model}} chapter identifies the physical effects that need to be captured, reviews existing research and motivates the finite element model that VirtualBow is built on.
The next two chapters develop this model in detail: \textit{\nameref{chap:system-equations}} introduces the general finite element framework and shows how individual elements combine into a single equation of motion for the whole bow.
\textit{\nameref{chap:element-equations}} develops the required element types for modeling the limbs, string and arrow.
With the model in place, the remaining chapters cover its solution.
\textit{\nameref{chap:static-solution}} treats the bracing and drawing of the bow, where the system is assumed to be in static equilibrium at every step.
\textit{\nameref{chap:dynamic-solution}} then handles the shot itself as a time-dependent process, determining the motion of the limbs, string and arrow.
