\chapter{Introduction}

VirtualBow is a software tool for designing and simulating bows.
This documentation explains the theory and reasoning behind the internal simulation methods that are used for computing the results.
It is still a work in progress and continues to evolve alongside the software, so it may not always be fully complete and up to date.

Reading and understanding this documentation is not required to use the software successfully - the user manual should be sufficient for that.
Instead, it serves as a reference for developers and interested users who want to learn more about the internals of VirtualBow.

For more information about VirtualBow, or to download the latest version of the software and this document, please visit \website.
